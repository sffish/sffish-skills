# review-manga-storyboards

審讀右翻漫畫的分鏡、name、草稿或完稿。檢查讀序、構圖、留白、鏡頭、panel beat、節奏、連戲，以及分鏡和劇本的差異；不生成或重畫漫畫。

## 檔案準備

一張圖片代表一頁，依頁碼命名：

```text
storyboard/scene-name/
├── 001.png
├── 002.png
├── 003.png
└── old/
    └── 002.png
```

- 建議使用 `001.png, 002.png, ...`；`1.png, 2.png, ... 10.png` 也能正確排序。
- 頁序只看檔名，不看建立時間、修改時間或 EXIF。
- 支援 PNG、JPG、JPEG、WEBP、TIF、TIFF。
- 舊版和比較稿放進 `old/` 等子資料夾，不要與現行頁面混在同一層。
- 一張圖只放一頁；跨頁仍分成兩個檔案，並在請求中註明。
- 若只提供部分頁面，請說明起訖與「尚未畫完」。

可用內附工具確認頁序：

```bash
python3 scripts/storyboard_manifest.py /path/to/pages
```

## 右翻讀序

預設由上往下、同排由右往左；同格的直排氣泡由右往左，每欄由上往下。skill 也會用氣泡尾巴、人物位置與對話因果判斷說話者。

除了格線，還會檢查大臉、黑白對比、動作方向和氣泡是否把視線拉去錯誤的位置。

## 最好提供劇本

`.txt` 或 `.md` 最方便。請提供檔案路徑，並說明：

- 對應章節或場次；
- 這批頁面是否完整；
- 分鏡或劇本哪一邊是現行 canon；
- 已知的刻意改編。

有劇本時，才能可靠判斷情節增刪、因果、角色動機、伏筆與正文矛盾。若分鏡為準，差異會列為「劇本待同步」，不會直接判成分鏡錯誤。

## 沒有劇本時

仍可檢查右翻讀序、構圖、留白、整頁視線動線、鏡頭、panel beat、節奏、翻頁、人物走位、道具與情緒是否清楚。

但無法可靠判斷是否漏掉原劇情、偏離角色動機，或和後文伏筆衝突。無法從畫面確認的內容會標成「不確定」，不會自行補故事。

## 使用範例

有劇本：

```text
使用 $review-manga-storyboards 審讀 /path/to/storyboard/scene。
右翻，對照 /path/to/manuscript.md；分鏡是現行 canon。
這批到第 12 頁為止，不做素描檢查。
```

沒有劇本：

```text
使用 $review-manga-storyboards 審讀 /path/to/storyboard/scene。
沒有劇本，只檢查右翻讀序、構圖、鏡頭和情緒節奏。
這是部分頁面，不要把尚未畫到的內容視為遺漏。
```

需要作畫檢查時另外指定：

```text
請加做素描檢查，標出具體頁碼與格子，檢查臉部透視、五官位置和手部接觸。
```

未明確要求時，skill 不評論草稿完成度；只有畫法已妨礙敘事辨識才會提出。
